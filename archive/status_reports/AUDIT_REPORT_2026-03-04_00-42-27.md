## 3) Findings (Prioritized)

- Evidence:
  - `traminex/seqtree.py:17` imports `seqturbulence` from `traminex.stats`.
  - `traminex/stats.py` no longer exports `seqturbulence`/`turbulence`.
  - `traminex/seqtree.py:57` calls `seqturbulence(...)`.

- Runtime impact:
  - `pytest -q` result: **45 errors during collection**, all cascading from `ImportError: cannot import name 'seqturbulence' from 'traminex.stats'`.
- Severity rationale:
  - Total package usability regression.

## 5) Architecture Assessment

### Strengths
- Clear functional partitioning (`stats_basic`, `stats_complexity`, `stats_utils`, distances, visualization modules).
- Optional accelerated backends with graceful fallback strategy in distance dispatcher.
- Strong ambition for parity tracking and broad test coverage footprint.

### Weaknesses
- Public API contract not centralized as a single source of truth (runtime exports, stubs, docs, and parity scripts diverge).
- Eager-import top-level facade is fragile for evolving APIs.
- Tooling pipeline (parity/docs consistency) lacks fail-safe behavior under partial breakage.
- High-complexity functions (notably `HSPELL_to_STS`) increase regression risk and review burden.

## 6) Recommended Remediation Plan

## P0 (immediate, blocking)
1. Fix import break by updating `seqtree` to new stats API (`seqtransn_count` / `turbulence_proxy`) and align feature naming.
2. Make `traminex` importable again; rerun full tests.
3. Regenerate stubs and parity artifacts only after import is healthy.
4. Enforce strict kwarg validation in distance entrypoints to reject unknown args.

## P1 (stabilization)
1. Establish one canonical API manifest (generated or declarative) used by:
   - `__init__.__all__`, stubs generation, parity scripts, docs checks.
2. Extend docs consistency script to validate real API names against manifest.
3. Resolve `seqstatf`/`seqstatl` `include_missing` contract mismatch.
4. Remove orphan stub modules and stale references (`visualization/export.pyi`, old turbulence names).

## P2 (quality and maintainability)
1. Reduce top-level eager import blast radius (lazy imports or segmented facades).
2. Refactor oversized conversion logic (`HSPELL_to_STS`) into tested helper units.
3. Clean invalid/duplicate artifacts (`TraMineR.tar.gz` 404 payload, generated parity drift, redundant data copies where possible).
4. Raise typing baseline (at least clean internal type errors; third-party stubs optional via types-* deps).
