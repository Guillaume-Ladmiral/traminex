## Executive Summary

This audit confirms the project intent is a Python sequence-analysis package inspired by TraMineR and TraMineRextras, centered on STS data structures, sequence statistics, distances (OM/LCS/LCP/RLCP/DHD/DUR/etc.), clustering/tree analysis, event analytics, multidomain weighting, and plotting.

The core runtime package is functional for covered paths (tests pass), but there are concrete correctness defects, broken examples/docs, stale verification tooling, and quality-gate gaps that should be addressed before considering this release fully production-ready.

## Findings (Severity Ordered)

### Critical

1. `seqstart` fails with labeled sequences when alignment introduces fill state
- Evidence:
  - Code path reuses old `labels` while recomputing a new alphabet: `traminex/seqformat.py:142-146`.
  - Runtime repro returns `ValueError labels must match alphabet length`.
- Impact:
  - Legitimate input can fail at runtime for labeled STS objects.
  - Affects alignment workflows and downstream pipelines.
- Recommendation:
  - In `seqstart`, remap/extend labels to new alphabet or set `labels=None` when alphabet changes.
  - Add dedicated tests for labeled inputs and fill-state introduction.

2. Public examples/docs contain non-existent API calls
- Evidence:
  - `examples/hspell_overlap_example.ipynb:34,43,52,66` uses `tx.seqiplot(...)` (removed name).
  - `docs/USAGE_new_apis.qmd:103,105` uses `tx.sequences.seqMD(...)` and `tx.sequences.seqMD_distances(...)`.
  - Runtime check: `tx.seqiplot` and `tx.sequences` both raise `AttributeError`.
- Impact:
  - User-facing examples fail immediately.
  - High trust/reliability impact for first release onboarding.
- Recommendation:
  - Replace `tx.seqiplot` with `tx.sequence_index_plot`.
  - Replace `tx.sequences.seqMD*` with top-level `tx.seqMD` and `tx.seqMD_distances`.
  - Add an automated example snippet validation step.

3. Multidomain weight APIs have unguarded invalid-input paths
- Evidence:
  - `seqMD_optimize_weights` divides by `weight_sum` without zero check: `traminex/multidomain.py:235-236`.
    - Repro: `init_weights=[0.0]` -> `ZeroDivisionError`.
  - `seqMD_gridsearch_weights` accepts empty `weight_grid` and returns `None`: `traminex/multidomain.py:123-157`.
- Impact:
  - Non-actionable return values and hard runtime exceptions.
  - Broken behavior for malformed but predictable inputs.
- Recommendation:
  - Validate non-empty grids and strictly positive total weight.
  - Raise clear `ValueError` with explicit remediation guidance.
  - Add tests for empty grid and zero-sum initialization.

10. Performance hotspots are avoidable
- Evidence:
  - Cross-set distance path computes full stacked matrix: `traminex/distances/__init__.py:485-488`.
  - Multidomain search repeatedly recomputes full channel distances for each candidate: `traminex/multidomain.py:136-138,257-260`.

- Impact:
  - Unnecessary O(n^2) and repeated heavy compute in larger datasets.
- Recommendation:
  - Implement rectangular kernels where available, cache per-channel matrices, and pre-index sequence strings.
